## 手工验收

以下为验收方法；没有执行的场景不视为已验证。涉及造数的场景使用独立的临时数据库，通过 DATABASE_PATH 指定，不修改个人学习数据。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 空历史 | db:init 后运行 history -- --user default --json | profile 为 null，两个列表为空，无新增用户 |
| 尚未初始化 | 指向不存在的 DATABASE_PATH 后运行 history | DB_NOT_INITIALIZED；不创建文件 |
| 最近三次 | 临时库中为同一用户写入四条 completed 和一条 in_progress；运行 history | 只返回最新三条 completed；时间相同时 id 大的优先 |
| 用户隔离 | 临时库加入两个用户及各自记录，分别指定 --user | 画像、学习和单词记录互不混入 |
| 已学词边界 | 临时库加入 learning_count 分别为 0 和 1 的词 | 只返回次数为 1 的词 |
| 重复初始化 | 在有记录的临时库上连续运行两次 db:init | 数据不变，无重复表，无清空 |
| 不兼容结构 | 临时库预建同名但字段不同的表，运行 db:init | DB_SCHEMA_INCOMPATIBLE，不改写已有表 |
| 无 AI 配置 | 未配置 AI 时运行 history 与 ai:check | history 正常；ai:check 提示 AI_CONFIG_INVALID |
| 代理正常 | 配置本地代理后运行 ai:check | 输出 ok: true、模型名和 OK；代理收到 Chat Completions 请求 |
| 代理失败 | 分别使用错误凭证、不可达地址或超时服务 | 对应认证、连接或超时错误；退出码 1，不输出凭证 |
| 非预期回复 | 代理返回空内容或非 OK 文本 | 明确报错，不视为通过 |
| 词书不存在 | 指定不存在的 BOOK_PATH 后运行 book:check | BOOK_READ_FAILED |

临时造数须满足 schema 中必填字段、外键与 JSON 约束；写入连接开启 foreign_keys。时间统一使用 UTC ISO 8601。
